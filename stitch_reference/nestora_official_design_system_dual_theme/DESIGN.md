# Nestora Official Design System

## Light Theme Palette
- Primary: #234B3A (Main actions, active navigation)
- Main Background: #F3F5F2 (Warm light grey canvas)
- Secondary Background: #ECEFEC (Subtle section fills)
- Card Surface: #FFFFFF (White content cards)
- Warm Ivory: #F7F6F0 (Accent containers, warm sections)
- Sage Green: #8FAF9A (Secondary accents, sub-status pills)
- Soft Green: #E7EFE8 (Selected states, badges)
- Pale Green: #DDEDE2 (Subtle highlights)
- Warm Accent: #D9A66F (Financial metric highlights, alerts)
- Main Text: #202B25 (High-contrast typography)
- Secondary Text: #78847C (Descriptive copy and captions)
- Border: #E3EAE4 (Subtle hairline divider)
